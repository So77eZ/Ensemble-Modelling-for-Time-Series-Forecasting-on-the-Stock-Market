## Слайд 2 — Актуальность, цель, задачи

**Заголовок**: Актуальность, цель и задачи исследования

**Тип**: 5 блоков по определениям, по одному в строке (см. ниже).

**Контент** (формат «определение»):

**Актуальность** — Российский фондовый рынок характеризуется высокой волатильностью и нелинейной природой ценовой динамики. Классические эконометрические модели (ARIMA, GARCH) не справляются с одновременной обработкой временных зависимостей и разнородного признакового пространства.

**Цель** — Разработка и исследование методики краткосрочного прогнозирования цен российского фондового рынка на основе стэкинг-ансамбля LSTM и градиентного бустинга с количественной оценкой неопределённости прогноза.

**Задачи**:

1. Анализ методов прогнозирования временных рядов и обоснование выбора стэкинг-ансамбля.
2. Проектирование архитектуры ансамблевой модели и формирование признакового пространства.
3. Программная реализация со стратегией прямого многошагового прогнозирования и адаптивными доверительными интервалами.
4. Экспериментальное исследование качества прогнозов на данных Московской биржи с множественным бэктестом для статистической значимости.

**Объект** — процессы краткосрочного прогнозирования цен инструментов фондового рынка методами машинного обучения.

**Предмет** — стэкинг-ансамбль LSTM и XGBoost с прямым многошаговым прогнозированием и адаптивными доверительными интервалами на базе GARCH.

**Применимость** (выделить отдельным блоком внизу, курсивом): программный комплекс универсален — модель работает с любым тикером Московской биржи через ISS API. Экспериментальная валидация проведена на 5 представительных голубых фишках 5 отраслей.

## Слайд 3 — Научная новизна и практическая значимость

**Заголовок**: Научная новизна и практическая значимость

**Тип**: 3 блока (Новизна / Значимость / Апробация).

**Блок 1 — Научная новизна** (нумерованный список):

1. Реализована стратегия прямого многошагового прогнозирования (Direct Multi-Step) в составе стэкинг-ансамбля — исключает накопление ошибки на горизонтах 2 и 3 дня.
2. Построены адаптивные доверительные интервалы на базе GARCH(1,1) — учитывают кластеризацию волатильности (выявленную тестом Льюнга-Бокса), в отличие от интервалов постоянной ширины.
3. Разработана методология валидации через множественный бэктест на 12 датах × 3 горизонта = 36 наблюдений с доверительным интервалом Уилсона для статистической значимости.
4. Индивидуальный размер обучающего окна для каждого горизонта прогноза ({h=1: 30, h=2: 30, h=3: 60} дней) — даёт +25 п.п. точности направления на 3-дневном горизонте.

**Блок 2 — Практическая значимость**:

- Программный комплекс применим для краткосрочного анализа любых ликвидных акций Московской биржи через ISS API (пользователь задаёт тикер при запуске).
- Открытый исходный код, воспроизводимая конфигурация (36/36 тестов).
- Адаптивные доверительные интервалы дают количественную оценку неопределённости прогноза.

**Блок 3 — Апробация результатов**:

- Обсуждение результатов на научно-методических семинарах кафедры ИТиЦЭ ИГХТУ.

## Слайд 5 — Архитектура ансамбля + per-horizon look_back

**Заголовок**: Архитектура ансамблевой модели

**Тип**: схема (двухуровневый стэкинг) с выноской справа про per-horizon look_back.

**Структура схемы (сверху вниз)**:

ВХОД:
- Тензор `(look_back, 46)` для XGBoost
- Тензор `(look_back, 7)` для LSTM
- где look_back ∈ {30 для h=1, 30 для h=2, 60 для h=3}

УРОВЕНЬ 0 — две параллельные модели:
- **LSTM**: 3 слоя · Dropout · EarlyStopping. Получает только 7 базовых временных признаков (OHLCV + Price_Change_1 + Vol_Return_10).
- **XGBoost**: на плоском тензоре полного признакового пространства.

Стрелки от обеих моделей вниз → блок «Стэкинг-вектор [lstm_pred, xgb_pred]».

УРОВЕНЬ 1 — мета-учитель:
- **Ridge(positive=True)** с подбором alpha через Optuna на OOS-предсказаниях. Для SBER: LSTM-вес ≈ 0.30, XGBoost-вес ≈ 0.70.

Стрелка вниз → блок «Точечный прогноз».

ДОВЕРИТЕЛЬНЫЙ ИНТЕРВАЛ — параллельная ветвь:
- Квантильная регрессия XGBoost на OOS-остатках walk-forward, ИЛИ
- GARCH(1,1) на остатках в рублях (адаптивный CI, новое в v16)

Финальный блок: «Точечный прогноз + 90% доверительный интервал».

ВЫНОСКА СПРАВА (отдельный блок с заголовком):

**Direct Multi-Step (MIMO)** — три независимых ансамбля для горизонтов h=1, 2, 3.

**Per-horizon look_back** — новое в v16:

- h=1: 30 дней
- h=2: 30 дней
- h=3: **60 дней** (длинный контекст для тренда)

Эффект на h=3: +25 п.п. точности направления, +0.41 IC.

| MAE (средняя абсолютная ошибка) | Средняя ошибка прогноза в рублях | Стандарт регрессии, интерпретируема |
| RMSE (среднеквадратичная ошибка) | √среднее(ошибка²) | Штрафует крупные выбросы сильнее MAE |
| MAPE (относительная ошибка) | Процентная ошибка | Сопоставима между активами с разной ценой |
| **R² на ценах** | Доля объяснённой дисперсии цены | ❗ Misleading для трендовых рядов (Naive даёт ~0.8 без модели) |
| R² на доходностях | Доля объяснённой дисперсии Δprice/price | Честная мера для финансовых рядов |
| Direction Accuracy + Wilson CI | Доля верных направлений + статистическая значимость | Для торговли направление важнее точной величины |
| IC (Spearman, Grinold-Kahn 2000) | Ранговая корреляция доходностей | Стандарт quant-индустрии: IC>0.05 значимо, >0.10 сильный сигнал |
| F1 (бинарная классификация направления) | Гармоническое среднее Precision и Recall | Сбалансированная оценка на несбалансированных выборках |
| Beats Naive % | Превосходство над «цена не изменится» | Нижняя планка полезности модели |
| CI Coverage | Доля случаев когда реальная цена в ДИ | Калибровка интервалов |

**Подпись внизу курсивом**:

> Стандартного регрессионного набора (MAE/RMSE/R²) недостаточно для финансовых рядов из-за их трендовости. Метрики из quant-индустрии (IC, DA, F1, Beats Naive) дают честную оценку прогнозной полезности, а Wilson CI и CI Coverage — статистическую значимость и калибровку.
>
> quant-индустрия — индустрия количественного управления инвестициями (quantitative finance), включающая хедж-фонды (Renaissance, Two Sigma) и алгоритмические подразделения банков.

**Особые пожелания**: строку «R² на ценах» выделить оранжевой рамкой и пометкой «❗ может вводить в заблуждение».
